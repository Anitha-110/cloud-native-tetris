# 🎮 Cloud-Native Tetris Gaming Platform

A modern full-stack Tetris gaming platform designed to demonstrate
cloud-native application development and DevOps practices.

## 🎮 Application Features

- Classic Tetris gameplay
- Player statistics
- Score tracking
- Global leaderboard
- Next piece preview
- Hold piece
- Ghost piece
- Level progression
- Line clearing
- Pause and resume
- Mobile controls
- Responsive gaming interface

## 🛠️ Technology Stack

### Application

- HTML
- CSS
- JavaScript
- Python
- Flask
- MySQL

### DevOps

- GitHub
- Docker
- Jenkins
- Kubernetes
- Prometheus
- Grafana

### Cloud

- AWS
